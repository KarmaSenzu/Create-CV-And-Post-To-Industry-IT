Mengembangkan dan memelihara aplikasi web fullstack berskala enterprise menggunakan JavaScript/TypeScript, React.js, dan Node.js/NestJS; merancang dan mengonsumsi arsitektur RESTful API serta integrasi database relasional (PostgreSQL & MySQL); mengoptimalkan rendering SSR/CSR dan caching; serta berkolaborasi dalam tim agile.

- Lulusan Sarjana Komputer (S.Kom.) atau keahlian setara
- Pemahaman yang kuat mengenai arsitektur kode bersih (Clean Architecture) dan version control Git
