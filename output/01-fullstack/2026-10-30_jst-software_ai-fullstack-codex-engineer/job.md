## Job Description & Context
PT. JST SOFTWARE INDONESIA (part of Jushuitan / JST ERP) is an omnichannel e-commerce SaaS ERP solution provider in Southeast Asia. The platform empowers cross-border and regional e-commerce merchants to consolidate multi-channel orders, inventory, logistics, and customer communications (including TikTok Shop, Shopee, Lazada, Tokopedia, Facebook Live, Messenger, WhatsApp, and courier logistics) into a unified high-performance ERP system.

We are looking for an **AI Full-stack Engineer / Codex Engineer** to leverage AI coding workflows (Codex, GitHub Copilot, AI agent tooling) to rapidly architect, develop, and deploy new B2B SaaS modules, third-party API connectors, and automated workflows from scratch.

---

## Responsibilities
- **AI-Driven Rapid Development**: Utilize Codex and AI-assisted programming workflows to rapidly scaffold and build production product modules.
- **Product Requirement Translation**: Break down Product Requirement Documents (PRDs) and business discussions into structured, testable engineering tasks.
- **Full-Stack Implementation**: Design relational database schemas, REST APIs, service layers, modern frontend interfaces, and background queue workers.
- **Third-Party Integrations**: Construct reliable API connectors for e-commerce platforms, logistics couriers, payment gateways, and Meta/WhatsApp messaging APIs.
- **Backend Reliability & System Management**: Implement robust webhook handlers, retries, idempotency mechanisms, job queues, and centralized error logging.
- **AI Code Review & Quality Control**: Rigorously review and validate AI-generated code prior to merging to prevent hallucinations, edge-case bugs, or security vulnerabilities.
- **Testing & Business Logic Integrity**: Author unit and integration tests for mission-critical e-commerce workflows (order processing, inventory synchronization, financial transactions, tracking).
- **Internal Tools & Admin Workflows**: Build internal administrative tools, reporting dashboards, and operational automation tools.
- **AI-Native Engineering Standards**: Assist in standardizing AI-native development workflows, including prompt templates, Codex task specifications, review checklists, and acceptance criteria.
